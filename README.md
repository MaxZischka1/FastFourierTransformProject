Synthesized on an ICE40UP5K using yosys and nextpnr. Pretty simple to make the project you can look [here](Makefile).
This build is for a 4 stage FFT but this can obviously be built up to N with a few tweaks. The 4 stage FFT is now working through all testbenchs and is working correctly. It operated at half the clock frequency HFOSC/2 being 24 MHz but I might try to adjust the critical path in mag2Bin to get the frequency up to 48 MHz. I am just waiting on the adc from digikey before I setup the display. To run the main testbench after looking at the file run make sim_top. After this run make yosys_synthesis and then finally run make next_pnrRep. This will show you everything I have made to date. All current outputs are available in json files being tracked.
